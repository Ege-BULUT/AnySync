0.1.0

2026-11-27
  • Device identity for macOS, Windows and Linux: an id, a name, a look and a key pair.
  • A private GitHub repo as the bus: devices, requests and transfers, with anything private sealed.
  • The item catalogue: every item with its path on each system, placed by name on the receiver.
  • Lists of installed tools made on the sender: Homebrew, winget, Scoop, apt, dnf, pacman, Flatpak, Snap, npm, cargo, pipx and editor extensions.
  • The encrypted device to device stream, resuming after a cut.
  • The command line: --scan, --give, --accept, --id.
  • The window: Device, Connect, Pick and Move, with device looks for each system, in a symmetric angular frame whose background lines fall into a vortex at its centre.
  • GOAL.md for your agent, and on a Mac a preflight script for Apple's command line tools, Homebrew and Node.
  • CI tests and builds on Windows and Linux.
