Get Any~Sync.

One app for both ends of the move, whichever systems they run.

macOSApple silicon.tar.gz ↓ Windowsx64.exe ↓ Linuxx64.tar.gz ↓

The window and the command line are one program, anysync. On macOS and Linux: tar -xzf the download, then ./anysync; on Windows, run the .exe. It needs the GitHub CLI signed in (gh auth login). Older releases are on the releases page.

The builds are not signed. On macOS, run xattr -d com.apple.quarantine ./anysync once if it is blocked; on Windows, SmartScreen asks once: More info, then Run anyway. On Linux the window needs the usual X11 or Wayland libraries. There is no Intel Mac build yet.
